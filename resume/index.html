Research Experience

• QCVV Methods at Sandia's Quantum Performance Lab
Advisors: Corey Ostrove, Robin Blume-Kohout Summer 2023 - Present

Research in quantum characterization, verification, and validation (QCVV), with a focus on gate set tomography, gauge-invariant noise models, and the characterization of logical operations in quantum error correction.

  • Develop automated model selection methods using first-order gauge-invariant (FOGI) parameters to identify physically meaningful errors in quantum gate sets.
  • Co-developed a perturbative framework for small Markovian errors that uses FOGI properties to parameterize gate sets without gauge freedom and extract approximately gauge-invariant error metrics. Gauge-invariant error theory.
  • Contributed to research introducing logical gate set tomography for characterizing noisy error-corrected operations. The work characterized a universal single-qubit logical gate set in the seven-qubit Steane code on Quantinuum H1, tested for coherent and non-Markovian logical errors, and used emulator-based error attribution to connect physical noise sources to logical errors. Logical gate set tomography.
